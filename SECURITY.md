# Security

OceanMail 0.2 is experimental; this repository has no production support
or safety certification. Follow the
[organization security-reporting policy](https://github.com/OceanMail/oceanmail-project/blob/main/SECURITY.md).
Do not disclose secrets, private data or vulnerability details in public issues.
GitHub private vulnerability reporting is enabled (administrator API verified
2026-09-26). Use Security → Report a vulnerability in this repository. A
non-maintainer end-to-end submission has not been tested. If the control is
unavailable, request a private reporting channel without posting sensitive details. Source publication does not authorize
radio operation or production deployment.
